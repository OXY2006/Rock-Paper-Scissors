# Rock Paper Scissors Game 

A simple and interactive Rock-Paper-Scissors game built using HTML, CSS, and JavaScript. Play against the computer and see who reaches the highest score first!


## Features

- Clean and responsive UI
- Emoji-based button design
- Live score tracking for both player and computer
- Random computer move generation
- Visual win/loss feedback with colored results

---

##  Tech Stack
- HTML5
- CSS3
- JavaScript
